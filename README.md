# 律衡 - 律师事务所业务管理系统

基于 Web 的律师事务所综合业务管理平台。

## 技术栈

- **React 19** + **TypeScript** - 前端框架
- **Vite** - 构建工具
- **Tailwind CSS v4** - 样式系统
- **Zustand** - 状态管理
- **React Router v7** - 路由
- **Recharts** - 图表可视化
- **Lucide React** - 图标库

## 功能模块

| 模块 | 说明 |
|------|------|
| 工作台 | KPI 概览、案件状态分布、类型统计图表、近期日程、团队负载 |
| 案件管理 | 案件 CRUD、状态/优先级筛选、详情查看、关联客户与律师 |
| 客户管理 | 客户信息维护（个人/企业）、关联案件查看 |
| 律师团队 | 律师档案管理、专业领域标签、在办案件统计 |
| 财务管理 | 账单列表、收款统计、状态筛选、费用明细 |
| 日程安排 | 月历视图、日程创建/删除、事件类型标记、即将到来列表 |
| 文档管理 | 文档分类统计、上传/删除、关联案件 |

## 开发

```bash
npm install
npm run dev
```

## 构建

